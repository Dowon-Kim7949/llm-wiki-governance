# Review History

이 문서는 무거운 위키 문서의 `## Review Notes` 이력 아카이브입니다. 각 원문서는 최근 5건만 유지하고, 그보다 오래된 항목은 여기로 옮깁니다(항목 원문 그대로, 수정 없음). 이 이전은 세션마다 선적재되는 어댑터 문맥에서 지시가 아닌 감사 추적을 덜어내기 위한 것이며, append-only 변경 로그는 [log.md](log.md)가 계속 소유합니다.

- 이 문서는 아카이브 전용입니다: 새 review note는 원문서 `## Review Notes`에 먼저 쌓고, 원문서가 5건을 넘으면 오래된 항목을 이 문서의 해당 섹션 **끝에** 옮겨 붙입니다(항목 순서는 오래된 것 → 새것).
- 항목의 검토·승인 효력은 frontmatter(`reviewed_by`/`reviewed_at`)가 정본이며, 이 아카이브는 서술 이력일 뿐입니다.
